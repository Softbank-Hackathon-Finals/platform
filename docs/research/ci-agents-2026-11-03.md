# 플랫폼 CI와 S2 실패 분석 워커: 비교 조사와 구현 근거

확인일: 2026-11-03 KST. 범위: 공개 공급자 문서, 공개 SDK 배포본, 로컬 Railshot 소스. 외부 제품의 테넌트·모델·운영 클라우드는 실행하지 않았다. 아래 **관찰**과 **우리 설계 제안**을 구분한다.

## 0. 조사 후 반영한 11/3 방향

OpenAI Responses를 기본 호출 경로로 구현한다. 아래 Claude SDK 분석은 선택형 어댑터의 제한 검증에 적용한다. 11/2 회의의 세분화 가능 의견과 Bedrock 미결 사항은 [ADR-0006](../adr/0006-model-provider-and-s2-ci.md)에 대조했다. ‘정본’과 행 번호는 조사 당시 v0.2이며 이번 v0.3은 팀 검토 전 제안이다. 연구 결과와 실제 AWS 실행 증거는 구분한다.

## 1. 적용 결론

팀 정본 `team-platform/docs/design.html:1182`는 별도 CI 에이전트를 두지 않고 S2의 실패 분석·수정·재시도를 재사용한다고 명시한다. FR-5(:371), T11(:1858), T15(:1907)에 맞춰 **T11 워커가 제안을 만들고, T15가 격리 적용과 비공개 검증을 실행**한다. 판정기·Executor에는 LLM 의존성을 추가하지 않는다. 저장소 CI의 경로별 실행 선택은 이 S2 워커와 별개의 결정적 절차다.

권장 경계는 네 개면 충분하다.

1. **결정적 조정기:** 요청·원본 revision·정책 version을 고정하고 최대 3회 시도, 시간·비용 상한, 취소, 상태 전이를 소유한다.
2. **T11 제안 워커:** 허용된 원본과 실패 요약을 읽고 JSON 제안을 반환한다. 쉘·운영 자격증명·배포·판정 권한은 없다.
3. **T15 도구 계층·리허설:** 허용된 제안만 리허설 namespace에 적용하고 신뢰된 별도 검증 Job을 실행한다. 비공개 테스트는 워커에 제공하지 않는다.
4. **증거·승인·T31 반영:** 입력 revision, patch digest, 정책 digest와 검증 receipt가 일치하는 결과만 승인 대상으로 전달한다. 승인된 동일 산출물의 반영은 기존 T31이 맡는다.

새 범용 CI DSL, 추가 다중 에이전트 감독자, 독립 큐·DB·승격 엔진은 이 범위에서 필요하지 않다. 아래 제품들은 원칙과 작은 경계를 참고하는 대상이며 플랫폼을 통째로 복제하는 대상이 아니다.

이번에 [PyPI JSON](https://pypi.org/pypi/agenticstar-platform/json)과 공개 wheel을 새로 읽었다. 현재 버전은 **3.2.1**, SHA-256은 `675a4c2c5ac2fbcc5669de8514d43a9d13a9c5fbe4d742083ad59dadf1a50829`로 공시 해시 및 기존 REA 대상과 같다. `workflow/files.py`의 symlink 차단, `runner.py`의 입력 무결성·cleanup 불명 처리, `envelope.py`의 외부 효과 삼상값을 표준 라이브러리로 정적 재대조했다. 패키지를 import하거나 실행하지 않았다. 현재 세션에 REA MCP/CLI는 없으므로 새 REA 실행이라고 표시하지 않는다.

주의할 점은 문서와 차트 버전 차이다. 기존 Helm 3.2.0 정적 조사에는 중앙 egress gateway와 cycle 기본 차단 변경이 있지만, 현재 control guide는 cycle 기본 외부 허용을 설명한다. 실제 설치 override도 비공개다. 어느 하나를 제공 테넌트 실측으로 승격하지 않는다. 우리 구현은 이 기본값을 추정하지 않고 명시적 deny 정책을 설치·검증해야 한다.

## 5. Claude Agent SDK를 T11에 연결하는 최소 경계

현재 [PyPI](https://pypi.org/pypi/claude-agent-sdk/0.2.177/json) 최신은 **0.2.177**이다. 소스 배포본 400,216 bytes를 정적으로 읽었으며 SHA-256 `4202e9ca65243e11d3dd74f00b55af6c3995169d3e634dd3397c76fd325800e1`가 공시값과 일치했다. 아래는 공급자 문서와 해당 sdist에서 확인한 내용이다.

### 도구와 권한

- `allowed_tools`는 자동 승인 목록이다. 이것만으로 다른 도구를 제거하지 않는다. `can_use_tool`은 앞에서 자동 승인된 호출에 실행되지 않는다. 따라서 매 호출의 강제 검사는 `PreToolUse`와 handler 내부에 둔다. [권한 흐름](https://code.claude.com/docs/en/agent-sdk/permissions)
- `tools=[]`는 builtin을 제거한다. `@tool`과 `create_sdk_mcp_server`로 원본 읽기·제안 제출만 제공하고 `mcp__<server>__<tool>` 정확한 이름을 허용한다. `permission_mode="dontAsk"`, `strict_mcp_config=True`, `setting_sources=[]`, `skills=[]`로 비대화형 실행과 외부 설정 유입을 제한한다. [custom tools](https://code.claude.com/docs/en/agent-sdk/custom-tools), [Python API](https://code.claude.com/docs/en/agent-sdk/python)
- JSON Schema 출력을 켜면 SDK가 내부 `StructuredOutput` 도구를 추가한다. 전역 hook은 이 응답 전용 도구를 구별해야 한다. 도구 호출의 원시 JSON 대신 `ResultMessage.structured_output`을 사용하고, success여도 값이 없으면 실패로 처리한다. JSON Schema만으로 revision·digest·허용 경로의 의미까지 검증되지는 않는다. [구조화 출력](https://code.claude.com/docs/en/agent-sdk/structured-outputs)

### 프로세스·인증·샌드박스

- SDK는 `claude` 자식 프로세스를 실행한다. 라이브러리 호출 하나가 stateless HTTP 요청인 것처럼 배치하지 않는다. 실행별 cwd와 `CLAUDE_CONFIG_DIR`, `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`을 둔다. `setting_sources=[]`만으로 자동 메모리는 꺼지지 않는다. [Hosting](https://code.claude.com/docs/en/agent-sdk/hosting)
- 0.2.177 `transport/subprocess_cli.py:819`는 부모 환경을 상속한 뒤 options.env를 덮는다. 따라서 **env={}는 credential 제거가 아니다**. worker 프로세스를 시작하는 계층에서 최소 환경으로 만들고, 공유 서버의 os.environ을 요청마다 수정하지 않는다.
- 모델 credential은 플랫폼 gateway에 둔다. SDK의 `ANTHROPIC_BASE_URL`을 gateway로 지정하고, workload sandbox는 credential을 받지 않는다. SDK 도구 제한은 OS·네트워크 격리를 대신하지 않는다. 비 root, capability 제거, read-only root, 제한된 scratch, ServiceAccount token 미장착, egress deny와 별도 verifier를 함께 확인한다. [공급자 secure deployment](https://code.claude.com/docs/en/agent-sdk/secure-deployment)
- 제품 서비스의 모델 호출은 API credential 또는 지원 cloud provider 경로로 구성한다. 개인 Claude 구독 token을 팀 공용 서버로 복제하지 않는다. 본인이 공식 flow로 무수정 Claude Code에 직접 로그인하는 사용과 플랫폼이 사용자를 대신해 credential을 중계하는 것은 구분된다. 실제 사용 가능한 credential 유무·계약은 이 조사에서 확인하지 않았다. [공급자 인증 규정](https://code.claude.com/docs/en/legal-and-compliance)

sdist에서 확인한 정확한 코드 위치: `types.py:25` permission enum, `types.py:2386` strict MCP, `types.py:2678` skills, `_internal/transport/subprocess_cli.py:592` tools→CLI, `:700` strict MCP, `:729` setting sources, `:819` 환경 상속. 이 자료는 API 지원 확인이며 실제 모델 호출 성공 증거는 아니다.

## 6. 구현 검증에서 빠뜨리지 않을 사례
