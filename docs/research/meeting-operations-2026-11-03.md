# 회의 전체 기록과 운영 인프라 요구 대조

확인일: 2026-11-03 KST. **회의록에 실린 네 날짜의 전체 본문을 최신순으로 읽고, 이후 Slack 운영 요청과 팀 저장소 정본을 대조했다.** 가장 먼저 필요한 것은 T6 출발지와 T7 플랫폼의 실제 실행·접속 경로다. CI 개선이나 워커 코드만으로 이 두 환경의 운영 준비가 완료되지는 않는다.

이 보고서는 읽기 전용 조사 결과다. 사람 이름·연락처·계정 값·로컬 절대 경로를 옮기지 않았고, 회의 원문은 공개 저장소에 복사하지 않았다. 회의 발언, 채택된 계약, 구현 기록, 실제 운영 검증을 구분한다.

## 1. 적용 순서와 정본

1. **현재 사용자의 명시 지시**: OpenAI(OAI)를 기본으로 사용하고 Bedrock은 보류한다. 사용자 AWS·GCP 계정을 쓰되 팀원 초대·접속정보 배포는 사용자가 먼저 사용한 뒤 회의에서 결정한다. PR은 현재 head의 필수 CI와 사람 한 명 이상의 승인, 변경 요청 해소 후 병합한다. 리뷰 요청은 해당 파트의 주·보조 모두를 고려한다. 월 예산 기준은 50만원이다.
2. **팀의 현재 정본**: `develop`의 설계 v0.2, `docs/tasks.md`, 운영 규칙과 실제 GitHub 이슈·브랜치 규칙을 본다. 이번 대조의 고정 커밋은 `440a7a25d8a0052d18c325961991d66ebe518b1b`이며 원격 develop도 같은 값임을 확인했다. 현재 이슈가 진행 상황의 기준이고, 체크박스가 남았다고 이미 병합된 개별 구현까지 없다고 단정하지 않는다.
3. **회의의 채택 결정과 후속 역할표**: 결정 시점·정본 반영을 함께 본다. 회의가 더 최근이라는 이유만으로 그 안의 질문·제안·미결 항목을 채택된 계약으로 승격하지 않는다.
4. **초기 아이디어·개인 데모·리서치·보안 추가안**: 구현 참고 자료다. 정본과 현재 사용자의 지시를 바꾸는 근거로 단독 사용하지 않는다.

[WorkGuide](https://app.notion.com/p/40c8bee9ada4802fb712d2df18eeb6e0)는 규칙의 원본이 저장소라고 명시한다. 그러나 그 페이지의 main 중심 흐름·승인 0명·squash 설명은 현재 develop Gitflow 및 사용자 지시와 다르다. 실제 GitHub의 main/develop effective rulesets는 각각 **승인 1명, 필수 secrets·infra·platform**이다. 저장소 정본의 `tasks.md`에도 ‘리뷰 승인 불필요’가 남아 있으므로 문서 동기화가 필요하다. 과거 회의의 CI 자동 병합 합의로 현재 승인 조건을 생략하지 않는다.

정본 링크: [설계 v0.2](https://github.com/Softbank-Hackathon-Finals/platform/blob/440a7a25d8a0052d18c325961991d66ebe518b1b/docs/design.html), [작업 계획](https://github.com/Softbank-Hackathon-Finals/platform/blob/440a7a25d8a0052d18c325961991d66ebe518b1b/docs/tasks.md), [Gitflow·검증 규칙](https://github.com/Softbank-Hackathon-Finals/platform/blob/440a7a25d8a0052d18c325961991d66ebe518b1b/docs/development.md).

댓글은 모든 하위 블록·resolved 포함으로 추가 조회했으나 네 건 모두 `suggested_edits_status=upgrade_required`만 반환했다. 댓글 본문이나 개수는 확인하지 못했다. 이는 댓글이 없다는 증거가 아니다. Notion의 연결 소스 검색과 meeting-notes query도 현재 플랜에서 제공되지 않아 사용하지 않았다. 알려진 Slack 스레드는 Slack 직접 도구로 읽었다.

## 10. 누락·한계와 다음 확인

- 범위는 현재 Bravo 회의록 인덱스에서 발견한 **모든 네 날짜**다. 인덱스 밖의 미등록 회의, 검색되지 않는 메시지, 다른 팀/예선의 과거 회의를 모두 망라했다는 뜻은 아니다.
- 작성된 전체 회의 내역을 읽었지만 원시 음성 전사본은 별도로 반환되지 않았다. truncation·unknown block 수 메타데이터도 명시되지 않아 그 부분은 확인 불가로 남긴다.
- Notion 댓글과 제안 편집은 플랜 제한으로 본문을 확인하지 못했다. 알려진 후속 역할표·운영 요청 Slack 스레드는 직접 읽었으며 각 스레드의 끝까지 확인했다. 공개 채널 검색은 결과가 없었으므로 Slack 전체 기록을 검색 완료했다고 하지 않는다.
- 추가 privacy 검토 문서의 실제 원본 URL은 이 조사에 전달되지 않았다. 확인하지 못한 페이지를 읽은 것처럼 대조표에 넣지 않았다.
- 최신 사용자 OAI 기본·Bedrock 보류·계정 사용 및 팀원 배포 보류는 **현재 세션의 실행 지시**로 기록했다. 팀 회의의 채택 결정과 구분하며 Notion에 없는 발언을 만들지 않았다.
- 기준 develop SHA와 이슈·ruleset은 조사 시점의 스냅샷이다. 이후 PR 병합·설계 변경은 새 근거로 갱신해야 한다. 이 보고서는 코드 수정·초대·권한 배포·클라우드 변경·외부 게시를 수행하지 않는다.
