# ADR-0005: T33의 범위 제한 인증과 실패 보존

- 상태: 제안 (T33 보강 PR 검토 대상)
- 범위: 보안 탐지 서비스. 플랫폼 로그인·T19 승인 판단은 변경하지 않는다.

## 배경

조회·유지보수 요청의 인증 누락, 정규화 실패 후 정상 수집 표시, 역순 이벤트의 최신 결과 덮어쓰기, 자유 서술 필드의 비밀 보관, 침묵 기반 자동 해결이 로컬 시험에서 재현됐다.

## 결정

1. 모든 데이터 요청에 환경·작업·출처·유효기간을 제한한 서비스 인증을 적용한다. 토큰은 해시로 검증하고 T10의 로그인·소유권 판단과 연결한다.
2. 탐지 결과·수집 상태·커서·접수 감사의 반영을 원자적으로 수행한다. 격리 이력은 정상 heartbeat로 해제하지 않는다.
3. 이벤트의 출처 시각을 대조하고 동일 시각 충돌은 보류한다. 식별자 마스킹으로 원본 ID가 충돌하지 않도록 해시 UID를 사용한다.
4. 저장 입력은 허용 필드 투영본으로 최소화한다. 오류 원문을 반환하거나 기록하지 않는다.
5. Falco 침묵 기반 해결을 금지한다. 해결 증거·승인 계약이 없으므로 해당 API를 410으로 폐기한다.

## 결과와 한계

인증·정규화 계약은 이전 버전과 호환되지 않는다. 소비자 갱신과 과거 DB 검토·재수집이 필요하다. 기존 DB를 자동 삭제하지 않는다. 레지스트리 발급·회수, 격리 보류의 증거 기반 해제, 불변 감사와 HA 저장은 별도 운영 통합 인수 대상이다.

세부 계약과 시험 항목은 [T33 보안 경계](../security/detection-hardening.md)를 따른다.
