# 실제 관측 연결과 브라우저 표시 검증

실제 로컬 앱·PostgreSQL·OTel Collector·Prometheus·T37 조회 API와 T21 HTTP 콘솔을 연결했다. `result.json`은 원문 SHA-256을 포함한 선택 필드 요약이며 공급자의 서명된 증명은 아니다.

- 출발·목적지 표시는 각각 로컬 앱 프로세스다. 각30초, 쓰기50/s·읽기150/s로 1,500개 쓰기와4,500개 읽기를 수행했다. 두 환경 모두 실패·유실·중복0, 관측 창3개 전달을 확인했다.
- T36 HTTP 수신과 재전송 거부, Collector의 클라이언트 인증서 없는 연결 거부를 확인했다.
- Chromium·WebKit에서 두 환경 지표 표시, 대상 Collector 종료 후 UNKNOWN/값 없음, 로그아웃 후 기존 지표 제거, 변경 버튼 비활성을 확인했다. 콘솔은 관측값을 게이트 승인으로 사용하지 않는다.
- 고정 시험 URL의 WebSocket 1012 종료·재접속과 동일 ID 재시도를 확인했다. 실제 AWS/온프렘 DB 전환이 아니다.
- 앱은 demo-chat PR #14·#15·#16과 첨부파일 조건부 생성 변경을 합친 별도 검증 체크아웃이다. 병합 완료나 운영 배포를 의미하지 않는다. 출처 커밋은 JSON에 기록했다.

첫 시험은 테스트 서버의 public_origin 포트 누락으로421, 두 번째는 브라우저 테스트가 일반 안내문에도 들어 있는 ‘권한’을 로그아웃 완료로 오인하여 실패했다. 실제 포트 결속과 정확한 권한 회수 문구를 확인하도록 시험을 고쳐 세 번째에 통과했다. 이전 실패 원문은 비공개로 보존한다. 인증 검사를 완화하지 않았다.

이 시험은 로컬 Nginx 진입점·공유 DB·모의 AWS API 및 시험용 신원/계획을 사용한다. 실제 Cloudflare/Tailscale, 팀 EKS/RKE2, 운영 로그인·승인·Executor 연결은 인수 전 별도로 확인해야 한다. 30초 통과는 별도1시간 부하 시험의 실패를 덮어쓰지 않는다. 실제 금융 서비스 운영 자격이나 무중단 이전 보장이 아니다.
