# T21 초기 비교 결과의 현재 계획 결속

T10에 저장된 초기 비교는 workflow 게이트 이벤트보다 먼저 존재할 수 있다.
기존 브라우저는 그 이벤트가 없으면 인증된 보고서도 `invalid_control_report`로
숨겼다. 이 회귀를 먼저 재현한 뒤 조회 화면만 보완했다.

- 기존 T21 보고서 응답에, 조회 전후 인증한 snapshot의 `plan_version`·`plan_state`를
  더했다. T10 API·상태 전이·승인 조건은 변경하지 않았다. T10 등록은 버전 1부터 시작하며
  0·음수·boolean 버전은 표시하지 않는다.
- 이벤트가 없을 때는 같은 계획·digest·환경 쌍·버전·상태·프로필,
  `initial` 단계·Application ID 없음과 승인 전 상태를 모두 요구한다.
  표시는 **초기 비교 (실행 허가 아님)**이다.
- 이벤트가 있으면 해당 gate/context 일치를 계속 요구한다. 충돌하는 이벤트,
  반영 후 단계, 승인/실행 이후 상태는 이벤트 없는 표시 경로를 사용하지 않는다.
  새 snapshot metadata가 없는 과거 보고서는 기존 이벤트 결속을 유지한다.
- 조회 시각부터 15초가 지나거나 현재 snapshot이 바뀌면 이전 표를 숨긴다.
  보고서 도착 시각을 기준으로 유효기간을 늘리지 않는다.
- 표시 결과는 승인·실행 조건으로 전달하지 않는다. 보고서의
  `authorizes_cutover`는 계속 false다.

## 검증

Python 전체 244개, JavaScript 전체 176개, Chromium 23개·WebKit 23개를 통과했다.
실제 SQLite/PostgreSQL 17.11, T10 HTTP·권한 검사, Ed25519 코드와 브라우저를 사용했으며
시험의 신원·발급자·보고서는 합성 자료다. 초기 BLOCK 표의 UNKNOWN 표시, 이벤트·승인
생성 없음과 승인/실행 버튼 비활성, 기존 승인·복귀·권한 회수 회귀를 확인했다.
타 계획·버전·상태·환경·프로필이나 기한이 맞지 않는 보고서도 거부했다.

첫 전체 실행은 샌드박스의 loopback/임시 DB 실행 제한으로 실패했다. 해당 시험을
생략하지 않고 허용된 로컬 실행 환경에서 전체를 재검증했다. 의존성·CI·시험 기한을
약화하지 않았다. 기존 Starlette/httpx 사용 중단 예고 한 건은 남아 있다.

이 기록은 운영 T10 원문 인수·등록 issuer·호스트 배포·실제 컷오버 완료를 뜻하지 않는다.
