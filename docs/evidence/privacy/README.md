이 커밋은 **공통 T1 공개 파일 2개**를 교정하고 검사·가림 도구를 제공한다. PR #77·#78 브랜치를 변경했다는 기록이 아니다. 조사 원본과 공개 전 원본은 저장소 밖 접근 제한 경로에 보존했다. [가림 manifest](redaction-manifest.json)의 원본 해시·공개본 해시를 분리했고, 기존 실측 입력의 해시·검사 결과·측정 수치는 변경하지 않았다.

로컬 검증은 scripts unittest 27개(개인정보 회귀 8개 포함), Ruff, actionlint 1.7.7, 공개 텍스트 패턴 검사, 원본 바이트/권한/SHA와 공개본 SHA 대조다. 클라우드 설정이나 실행 코드를 바꾸지 않았으며 새로운 클라우드 실행을 주장하지 않는다. 별도 gitleaks 8.24.3 검사는 develop 기반 이력에서 누출을 찾지 못했다. 현재 CI 실행 결과는 PR의 실제 검사 기록으로 확인한다.

현재 파일을 가려도 이전 커밋과 PR diff, 외부 캐시의 원문은 남을 수 있다. 이력 재작성·인증 정보 회전·자동 삭제는 수행하지 않았다. 바이너리·큰 파일·자유 서술 이름·사설 토폴로지·일반 URL의 수동 검토 필요성은 정책에 명시했다.

CLI 오류 처리 후속 검증: 추적 중인 파일을 staging 없이 이름 변경하면 Python traceback에 운영자 홈 경로가 나타날 수 있어, 입력·파일·Git 처리 오류를 값 없는 일반 문구와 실패 코드 `2`로 반환하도록 보완했다. 실제 subprocess CLI에서 삭제된 tracked 파일, 명시한 누락 파일, 잘못된 JSON, 존재하지 않는 repo, Git 실행 파일 부재 5개 경로를 확인했다. scripts unittest는 총 28개 통과했고 Ruff·공개 텍스트 검사도 통과했다.
