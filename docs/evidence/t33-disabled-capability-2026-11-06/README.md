# T33 미설정 탐지 기능 표시 수정 검증

2026-11-06. 팀 계정 서울 리전의 실제 GuardDuty를 개인 팀 SSO로 읽기 조회했다.
기존 수집기가 `NOT_ENABLED`를 기록했고 수정한 로컬 조회 모델은 network/runtime
탐지 능력을 `available: false`로 반환했다. 공급자에 쓰거나 탐지 서비스를 활성화하지 않았다.

`/sources` 형식의 FAILED/NOT_ENABLED와 요약의 THREAT UNKNOWN은 유지한다.
권한 거부와 시간 초과를 탐지 기능 부재로 해석하지 않는다. 다른 출처가 같은 기능을
제공하면 유지하며, 나중에 실제 수집이 성공하면 복원한다.

- lock 고정 sync, pytest 142개, Ruff 통과
- 회귀: 미설정(성공 이력 유/무), 복수 출처, 이후 복구와 늦은 실패 무시,
  권한 거부/시간 초과/수집 오류 구분, 인증 조회 API의 환경 범위 보존
- 실제 제공자 응답을 로컬 수집기·조회 모델로 소비한 시험이다.
  호스팅 화면 반영이나 실제 양성 탐지 수집을 검증한 것은 아니다.
- 등록되지 않은 실험용 로컬 환경 식별자를 사용했으며 T10 계획 승인 근거로 쓰지 않는다.
