[AWS 결과](aws-test.json)의 실행 구간은 **14:06:34–14:06:50 UTC / 23:06:34–23:06:50 KST**다. 비관리자 UID, 임시 디렉터리 제거, 계정·대상 소유 경계와 입력 17개 파일의 SHA-256을 확인했다. 게시 직전 각 해시를 checkout의 실제 파일 바이트와 대조했다. 운영 DB 접근, Kubernetes 변경, 실제 컷오버는 모두 false다.

AWS JSON은 제공자 전체 응답이 아니다. SSM 출력에서 경로를 포함할 수 있는 pytest stdout/stderr를 제외하고, 제공자 실행 시각·종료 상태를 추가한 제한된 공개 결과다. 소스 해시는 `path`와 `sha256` 필드의 배열로 표현했다. 해시값은 원본과 같으며, 파일명과 해시를 직접 연결한 표현이 API 키로 오인되는 것을 피한다. 전체 제공자 응답과 제출 코드는 비공개로 보존한다. 자격·계정·인스턴스 식별자는 공개하지 않는다.

- 같은 요청 재시도와 동시 접수에서 POST 1회, 다른 입력의 멱등 키 재사용 및 승인 재소비 거부.

준비 중 첫 PostgreSQL 시험은 시험 harness의 행 형식 차이 때문에 실패했고, 이를 고친 뒤 전체 검사를 통과했다. AWS 제출 전 소스 묶음의 로컬 크기 제한에 두 번 걸려 전송되지 않았으며, 범위를 제한한 48 KiB 이하 묶음으로 한 번 실행했다. 실패한 준비를 AWS 실행 실패 또는 컷오버 실행으로 세지 않는다.

호스트의 검증 포트에 실제 정본·승인·SHIFT를 연결하고 전용 CA의 실제 Executor와 통합해야 운영 검증으로 넘어갈 수 있다. 기본 인증/authority는 거부한다. 전체 T10 완료 기준은 아직 충족하지 않았다.

최초 PR CI의 비밀 검사는 파일명에 `api`가 포함된 세 SHA-256 메타데이터를 키로 오인했다. 공개 결과의 해시를 배열 형식으로 바꾸고 아직 리뷰되지 않은 자체 PR 커밋만 교정했다. 검사 예외나 워크플로 변경은 추가하지 않았다. 코드·시험 입력은 AWS 실행 당시 바이트 그대로다.
