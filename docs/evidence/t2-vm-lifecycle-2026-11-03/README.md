# T2 로컬 VM 수명 관리 보완 검증

PR #100의 기존 설치·CIS 측정은 수정 전 코드의 기록으로 보존한다. 이번 검증은
`local-vm.sh`의 시작·종료 잠금과 `local_vm.py`의 종료 경계에 한정한다.
시험한 코드 커밋과 파일 해시는 [results.json](results.json)에 있다.

PID 파일은 프로세스 신원을 보장하지 않는다. VM 생성 시 고유 UUID를 기록하고 QEMU에
전달하며, 종료 전에 프로세스 실행 파일·시작 시각·명령행과 QMP의 UUID·디스크를 함께
대조한다. 확인된 QMP 연결에 종료 명령을 보내고 실제 프로세스가 사라진 뒤 삭제한다.

| 시험 | 결과 |
|---|---|
| 실제 QEMU 11.1.3, 게스트 없는 `machine none`, 임시 디스크 | 공개 `local-vm.sh down` 경로에서 신원 확인·종료·디스크 정리 통과 |
| 비-QEMU 프로세스 PID와 이미 종료한 프로세스 PID | 종료 명령 없이 거부, 디스크 보존 |
| 0·1·음수·범위 초과·다중 PID·문자열 | 프로세스 제어 전에 거부 |
| PID 파일을 FIFO·symlink로 대체 | 블로킹·대상 접근 없이 거부 |
| UUID 없는 이전 상태·VM 디렉터리 symlink | 자동 삭제 거부 |
| 다른 QMP UUID·디스크, 종료 직전 프로세스 변경 | `quit` 미전송, 상태 보존 |
| QMP 종료 거부·응답 전 연결 종료·프로세스 생존 시간 초과 | 성공/종료로 오인하지 않고 상태 보존 |
| 실제 시험 프로세스 종료 전·후 | 종료 전 디스크 존재, 종료 확인 후 삭제, 반복 down 성공 |
| 다른 시작/종료 작업이 잠금을 보유 | 두 번째 명령 실패, 상태 보존 |
| 기존 VM에 다시 up·준비 과정 실패 | 기존 VM 보존·추가 시작 없음, 실패한 새 상태 보존 |

저장소 127개 시험(수명 관리 14개, 실제 QEMU 1개 포함), Ruff, Bash 문법과 공개 식별자
검사가 통과했다. 실제 QEMU 항목은 `BRAVO_TEST_QEMU`를 지정한 로컬 opt-in이다.
나머지 회귀는 Python 표준 라이브러리·격리된 시험 프로세스·Unix socket으로 실행하며
필수 저장소 CI에 포함된다. QMP 모의 응답 결과와 실제 QEMU 결과를 구분한다.

기존 VM·T6/T7 자원·공통 RKE2 bootstrap은 변경하지 않았다. 새 Ubuntu 설치, RKE2/CIS,
데모 머신, x86, Tailscale 연결을 이번 수정에서 재검증한 것은 아니다. 실제 시험 QEMU의
종료를 확인하고 시험 디스크를 정리했다. 의도적으로 실패시킨 사례도 시험 프로세스를
먼저 종료한 뒤 해당 임시 디렉터리만 정리했다. 원문 로컬 로그는 비공개로 보존한다.
