# T8 첨부 복사 Job 실제 경로 1회 실행 (2026-11-06)

**실제 경로에서 첨부 복사 Job을 한 번 돌렸고 판정은 `SUCCEEDED`다.** 출발지는 AWS S3와 출발지 DB, 목적지는 arm64 노드의 SeaweedFS다. 5초 만에 끝났고, 양쪽 객체 2개의 내용 해시가 같았다. 값은 [results.json](results.json)에 있다.

**리허설 값으로 돌렸다.** `plan_id`는 `rehearsal-t8-attach-1106`, `epoch`는 1이다. 컷오버 요청의 실제 값으로 컷오버 직전에 돌리는 정식 실행은 해피패스 단계로 남는다(T28). 순서는 [운영 안내](../../operations/t8-attachment-copy-job.md)대로 업로드 중지 → 복사 → 판정 → 가중치 전환 → 컷오버다.

## 공개하지 않은 값

Job · Pod UID, 객체 키와 내용 해시 목록, 버킷 · 계정 · 역할 · KMS 키 식별자는 넣지 않았다. 원본은 비공개 기록에 있다.

## 재지 않은 것

- 컷오버 요청의 실제 `plan_id` · `epoch`로 컷오버 직전에 돌리는 정식 실행. 해피패스에서 한다.
- 업로드를 멈춘 뒤 시작했는지(`started_at`) 대조. 이번에는 컷오버가 없어 기준 시각이 없다.
- 역방향 전환 뒤 목적지 쓰기가 출발지에 도착하는지(T8 완료 기준의 나머지). 컷오버 뒤에만 볼 수 있다.
