# T19: 양쪽 앱 경로에서 도달한 DB의 스키마·PK 조회

> **범위 정정:** 이 기록은 독립된 출발지·목적지 두 DB의 스키마 일치 증거가 아니다.
> 수집기는 양쪽 **앱의 `DB_HOST`**를 사용했다. 목적지의 앱 경로는 목적지 PgBouncer를
> 거친다. 수집 뒤인 20:44 KST에 확인했을 때 이 풀러는 컷오버 전 구성대로 **출발지 DB**를
> 가리켰고, 수집 당시의 연결 대상은 독립적으로 확인하지 않았다. 따라서 두 결과가 서로
> 다른 DB를 읽었다고 볼 근거가 없으며, 일치는 동등성의 근거가 아니다. 정정과 목적지 CNPG 직접 수집은
> [t19-direct-database-2026-11-06](../t19-direct-database-2026-11-06/README.md)(#512)에 있다.
> 아래 원문·관측 시각·해시는 바꾸지 않고 보존한다.

2026-11-06 KST에 실제 EKS 출발지와 온프렘 목적지의 기존 앱 연결에서
`bravo_gate.t13.collect_schema`를 실행했다. 이 함수가 사용하는 T13
`schema_fingerprint`와 해시 규칙을 그대로 사용했으며 SQL/판정기를 복제하지 않았다.

| 확인 범위 | 결과 |
| --- | --- |
| public.messages | 두 앱 경로의 스키마 hash·PK 같음 (같은 DB일 수 있음, 위 정정) |
| public.attachments | 두 앱 경로의 스키마 hash·PK 같음 (같은 DB일 수 있음, 위 정정) |
| 수집기 오류 | 양쪽 없음 |
| 연결 | 인증서·호스트명을 검증하는 verify-full TLS, autocommit, 시작 전 idle |
| DB 역할 | 기대 DB·session/current role 일치, superuser/BYPASSRLS 없음 |
| 전후 자원 | 앱·Pod·ReplicaSet·서비스·Pooler·CA/자격 참조의 메타데이터 동일 |
| 변경·업무 데이터 | 업무 행 조회 0, 업무 쓰기 0, 시퀀스 변경 0 |

전용 읽기 전용 연결과 3초 statement timeout·1초 lock timeout을 사용했다.
T13이 테이블 카탈로그·PK를 읽고 재조회해 수집 중 변경을 확인했다.
비밀값은 기존 앱 프로세스 안에서만 사용했으며 DSN·SQL 오류 원문·채팅 본문을
수집 결과나 공개 증빙에 넣지 않았다. 임시 수집 코드 디렉터리는 종료 시 정리했다.

출발지는 등록 앱의 image·ServiceAccount·ReplicaSet 결속도 대조했다.
목적지는 공식 개인 단기 토큰과 직접 API로 현재 대상 클러스터·DB UID를 대조했다.
다만 앱 연결이 그 CNPG에 도달하는지는 확인하지 않았다(위 정정).
목적지의 기존 loopback Secrets Manager 호환 경로를 사용했으며, OpenBao 전환이
완료됐거나 두 자격 저장 방식이 같은 보안 수준이라고 주장하지 않는다.

## 운영 판정과의 구분

이는 실제 두 DB에서 정해진 두 테이블을 읽은 **수집기 자격 확인**이다.
운영 T10에 context·출처·정책·판정 등록을 수행한 것이 아니다. 참조한 실제 계획의
필드는 유지했고, 별도의 검증용 context/데이터 준비 정책을 사용했다.
그 정책이 운영 등록을 통과했거나 전체 이전 테이블을 포괄한다고 주장하지 않는다.

- 스키마 관측은 시작 시각 기준 최대 30초의 유효기간을 가진다. 이 문서는 과거
  사실 기록이며, 운영 평가 시점에는 새로 수집·인증해야 한다.
- 두 관측을 한 승인 창 안에서 소비한 것은 아니다. 공개 요약에 각각의 실제
  관측·만료 시각을 보존했으며 만료된 자료의 시각을 갱신하지 않았다.
- 업무 행 내용·건수·무결성은 읽지 않았다. 동일 스키마는 동일 데이터의 증거가 아니다.
- 복제 지연·시퀀스 보정 리허설 기록은 이번에 수집하지 않았다. 이 값들을 0이나
  성공으로 보충하거나 전체 T19 PASS로 보고하지 않는다.
- T10 실제 원문 저장·조회, 운영 issuer/현재 권한/T13 기록, T21 호스트 표시와
  T12/T17 실제 전환은 별도로 인수해야 한다. T19 완료 체크는 유지했다.

처음 목적지 시도는 원격 실행 전 로컬 Python에 jsonschema가 없어 중단됐다.
이미 잠긴 검증 환경의 Python으로 실행해 실제 수집을 완료했으며 운영 환경의
패키지·권한·설정은 변경하지 않았다. 출발지 임시 SSM 터널은 종료했다.

[summary.json](summary.json)은 공개 가능한 결과와 원문 해시다.
[source-manifest.json](source-manifest.json)은 실제 패키징한 T13/T19 소스에 결속한다.
전체 자원·연결·관측 원문과 전송 스크립트는 비공개로 보존했으며, 공개본만으로
운영 자원의 실체나 운영 권한을 독립 검증할 수는 없다.
