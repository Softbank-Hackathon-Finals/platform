# 실제 워크로드 지도와 보안 설정·T14 이력

2026-11-08 개발 인수 기록. [기존 실제 지도](live-workload-observations.md)를 확장했다.
이 화면은 운영 T10 승인·게이트·컷오버를 대신하지 않는다.

## 화면

- 실제 양쪽 Service·Pod·컨테이너 관계에 보안 설정 관측을 연결한다.
- Pod: 호스트 네트워크/PID/IPC 공유, 토큰 자동 마운트, 이를 선택하는 Ingress/Egress NetworkPolicy 수.
- 컨테이너: 특권·권한 상승·비루트 강제·읽기 전용 루트·capability 제거·Seccomp 선언.
- 주의 설정이 있는 자원을 주황색으로 표시한다. 카드에서 선택하면 지도 자원과 상세 설정을 확인한다.
- T14 보존 원문은 기존 `CONTROL_TESTS` 목록으로 시험 이름·당시 판정·증거 상태·재시험 필요 항목을 표시한다.

주의 표시는 호스트 자원 공유, 명시적으로 허용한 특권·권한 상승·토큰 자동 마운트,
명시적으로 해제한 강제 보호 설정, Unconfined Seccomp, 해당 방향의 선택 NetworkPolicy 부재에 적용한다.
미지정은 상속이나 다른 보호 기능을 조사하지 않은 상태다. 안전 또는 위반으로 채우지 않는다.
Pod의 비루트·Seccomp 상속은 반영한다. ServiceAccount의 토큰 상속은 읽지 않으므로 미확인으로 둔다.

**설정 주의와 공격 탐지·통제 실패는 다르다.** 정책이 선택한 Pod도 실제 접근 거부 시험 전에는 격리됐다고 표시하지 않는다.
정책 수는 Kubernetes NetworkPolicy만 센다. 다른 CNI 정책·호스트 방화벽·서비스 메시의 보호 효과는 판정하지 않는다.
주변 강조는 설정 관계상 연결된 자원이며, 실제 침해 확산이나 격리 범위가 아니다.
일반 컨테이너를 관측하며 init/ephemeral 컨테이너의 보호 수준 전체를 검증하지 않는다.

## 수집과 현재성

기존 tenant·앱·환경·클러스터 UID·namespace·Service 등록을 사용한다.
추가한 외부 호출은 같은 namespace의 Pod·NetworkPolicy 재조회다. exec·로그·Secret 읽기·쓰기 명령은 추가하지 않았다.
수집 전후 Service·선택 Pod UID/설정·NetworkPolicy 설정·클러스터 UID를 대조하고 변경·실패 회차는 철회한다.
기존 90초 한도와 브라우저 만료 검사를 유지한다. 원시 Pod spec·환경변수·이미지 주소·정책 이름·Seccomp 파일 경로는 내보내지 않는다.

`security_config`는 자원 ID·현재 UID에 결속한 허용 목록 값이다. 표시 그래프 밖의 별도 관측이며
각 노드의 `security`는 계속 `unknown`이다. 게이트·공격·격리 증거를 만들지 않는다.
생산자 hash는 수집기와 `security_configuration.py` 바이트를 함께 포함한다. 이전 단일 파일 hash를 재사용하지 않는다.

## 보존 T14 원문

호스트가 선택한 `RetainedRun`의 tenant·앱·환경·방향·환경 ref·프로필·원문 SHA-256을 고정한다.
소유자 전용 일반 파일, 크기 제한, 심볼릭 링크·중복 JSON 키 거부를 적용한다.
기존 T5 ControlRun 스키마와 등록 프로필의 필수 시험 집합을 검사한다. 누락·중복·통제 ID 불일치·범위 불일치·파일 변경은 표시를 철회한다.
시험 ID·당시 판정·증거 만료·미확인 사유만 표시하며 원시 관측값·로그·증거 URI는 보내지 않는다.

보존 원문은 항상 `HISTORY`, `current_resource_verified=false`, `authorizes_execution=false`다.
원문 hash는 바이트 식별자이며 생산자 인증·현재 자원 결속·계획 승인 근거가 아니다.
유효기간이 남았더라도 `RECORDED`는 현재 운영 PASS로 바뀌지 않는다.
운영 결과는 기존 T10 저장·조회와 T19 검증을 거쳐 별도로 인수한다.

실제 연결한 원문은 양쪽 각각 20개다. 각 실행의 기록은 PASS 1개·UNKNOWN 19개이며 PASS 증거는 이미 만료됐다.
이 표는 새 시험 실행이 아니라 현재 앱·자원과 같은 계획에서 재시험할 항목을 확인하는 준비 화면이다.
