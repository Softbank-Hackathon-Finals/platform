# 워크로드 대응 지도: 5분 확인 순서

이 문서는 로컬 미리보기용이다. 화면의 모든 계획·자원·효과는 합성 시험 데이터다.
실제 공격을 탐지하거나 클라우드 자원을 격리하는 시연으로 설명하지 않는다.

## 1. 현재 화면과 출처 확인 — 30초

Sova 워크스페이스에서 워크로드 지도를 연다. 기본은 `플랫폼 관측`이며 생산자가 없으면
미연결로 표시한다. 로컬 미리보기의 `서버 합성 시험`은 HTTP 조회와 권한 경계를 시험할
자료이며 실제 환경 관측이 아니다.

기존 승인·환경 이전·보안·모니터링 화면은 그대로 사용한다. 등록된 출발지·목적지는
`등록된 이전 경로 보기`에서 확인한다.

## 2. 정상 관계와 보안 이상 — 1분

`로컬 시나리오`를 선택하고 `격리 후 대체`를 고른다. `다음 단계` 또는 `자동 재생`을 누른다.
진입점, API, 작업자, DB와 보호·실행 구성 요소가 연결된 상태에서 API에 보안 이상이 나타난다.

API를 선택하면 근거, 유효 시각, 연결 상태를 오른쪽에서 확인한다. Shift와 함께 여러 자원을
선택할 수 있다. 주변 강조는 의존성에 따른 영향 가능성이며 다른 자원의 침해 확정이 아니다.

## 3. 보류·승인·부분 격리 — 1분

보류, 승인, 차단 요청과 차단 확인을 구분해서 보여 준다. API와 작업자만 격리되고 지정된
연결에 끊김 표시가 생긴다. DB 등 나머지 자원은 격리됐다고 표시하지 않는다.

이 시나리오에서 승인 버튼이나 노드 선택은 실제 승인·실행 요청을 보내지 않는다. 아래
T10·T19 패널의 기존 계획 기록도 합성 시나리오의 권한 근거로 쓰지 않는다.

## 4. 대체·검증·전환 — 1분

대체 실행본 준비 후 독립 검증, 경로 전환, 서비스 복구를 차례로 확인한다. 응답 복구 이후에도
원본의 격리와 사고 보류는 유지한다. 사고 종료나 원본 재개는 별도의 판단이다.

이 장면은 기존 DB를 다시 사용하는 관계를 표시한다. DB 데이터 이전·쓰기 단일성·무중단
운영을 검증하는 시연이 아니다.

## 5. 실패와 근거 만료 — 1분 30초

`대체 검증 실패`를 선택해 다시 재생한다. 대체 실행본 검증이 실패하면 경로 전환과 복구를
완료로 표시하지 않는다. 이어 `근거 만료 보기`를 눌러 현재 성공 표시가 미확인으로 바뀌고
과거 기록은 남는지 확인한다.

마지막에는 `플랫폼 관측`으로 돌아와 현재 연결 상태를 보여 준다. 실제 격리·복구 시연에는
인증된 생산자, 실행·독립 검증 영수증, 실제 환경 인수가 추가로 필요하다.

계약과 남은 연결은 [워크로드 대응 지도](workload-response-view.md)를 따른다.
