        변경·전환 승인

        계획·이미지·변경·게이트의 결속 값을 확인한 후 승인합니다. 승인은 즉시 전환을 실행하지 않습니다. S2 변경 승인은 검증된 코드 변경에 대한 승인 기록이며, 배포 실행은 별도입니다.

        검증된 보고서 미연결

        시험 ID 출발지 목적지 보안 판정 근거 코드

        기록된 보안 시험 결과입니다. 데이터 준비·운영 승인·실행 직전 재검증을 포함한 전체 전환 허가를 뜻하지 않습니다. EXCEPTION은 동등성 통과와 구분한 승인 예외입니다.

        보안 탐지 수집 현황

        보안 탐지 조회 미연결·만료

        출발지·목적지 환경 전체의 수집 결과입니다. 이 앱만의 결과나 이전 허가를 뜻하지 않습니다.

        범주 출발지 목적지

        0건은 연결된 출처에서 수집한 미해결 탐지가 없다는 뜻입니다. 탐지 출처 없음·수집 실패·오래된 결과는 0건 또는 보안 통과로 표시하지 않습니다.
